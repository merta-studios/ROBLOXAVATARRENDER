# Lokale Hintergründe

Hier abgelegte Bilddateien können in `configs.json` über ihren Dateinamen (mit oder ohne Erweiterung) ausgewählt werden. Unterstützt werden PNG, JPG/JPEG, WebP, TIFF und BMP. Bilder werden als Image Texture auf das Mesh-Plane `Background` in `WomanRig.blend` gelegt.

Der gewünschte GFXRhino-PFP-Background-Pack ist kostenlos auf der [Produktseite](https://gfxrhino.com/products/pfp-background-pack/) verfügbar. Die Seite leitet den Download über einen clientseitig erzeugten Download-Button weiter; der direkte ZIP-Datei-Endpunkt ist aus dieser Sandbox nicht abrufbar. Bitte das ZIP dort herunterladen und die gewünschten PNG-Dateien hier ablegen. Die Produktseite nennt 20 Hintergründe in 1920×1920 sowie PNG-Vorschauen und PSD-Quelldateien.
